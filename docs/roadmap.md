# Roadmap

Jenkins Build Evidence Exporter is intentionally developed as a small and focused project.

The roadmap describes the project's current direction and provides contributors with potential areas to work on.

## v0.1 — Initial Release

The first version focuses on the basic evidence export workflow.

- [ ] Jenkins plugin project setup
- [ ] Collect build metadata
- [ ] Collect build status
- [ ] Collect build timing
- [ ] Collect Git information
- [ ] Generate JSON evidence
- [ ] Store evidence as a Jenkins build artifact
- [ ] Basic automated tests
- [ ] Installation documentation

## v0.2 — Improved Evidence Export

- [ ] Collect artifact metadata
- [ ] Manual evidence export
- [ ] Improve configuration UI
- [ ] Improve error handling
- [ ] Expand test coverage

## v0.3 — Pipeline Support

- [ ] Jenkins Pipeline integration
- [ ] Pipeline evidence export step
- [ ] Improve documentation for Pipeline users
- [ ] Add examples for common Pipeline configurations

## Future Ideas

Potential future work includes:

- External storage integrations
- Additional evidence types
- Evidence schema improvements
- Evidence validation
- Additional Jenkins metadata

Future features are not commitments. They may change based on user feedback and community contributions.

## How the Community Can Help

Contributors can help with any part of the roadmap.

Small contributions are welcome, including:

- Documentation
- Tests
- Bug fixes
- Examples
- Error handling
- Evidence schema improvements

If you want to work on a larger roadmap item, please open an issue before starting implementation so that the proposed approach can be discussed publicly.
